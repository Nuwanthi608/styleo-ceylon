# 🌿 CEYLON BOTANICS | Organic Wellness & Herbal Essentials

**Ceylon Botanics** is a modern Sri Lankan wellness and organic essentials e-commerce landing page. Built as part of **DecodeLabs Industrial Training (Project 1)**, this application demonstrates pure frontend capabilities, responsive architecture, and interactive user interfaces using core web technologies without reliance on external frameworks.

---

## ✨ Features & Highlights

* 📱 **Mobile-First Responsive Design:** Seamless layout adaptation across mobile, tablet, and desktop screens using CSS Grid and Flexbox.
* 🌿 **Warm & Grounded Aesthetic:** Designed using a natural color palette inspired by authentic Sri Lankan herbal wellness.
* 🛒 **Interactive UI Elements:** Dynamic cart counter, slide-out cart drawer, and smooth scrolling navigation.
* 🌸 **Curated Elixirs Display:** Beautiful product showcases for pure cinnamon bark oil, blue lotus tea, and herbal serums.
* ♿ **Semantic & Accessible:** Built with HTML5 semantic landmarks (`<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`) ensuring web accessibility and SEO optimization.

---

## 🛠️ Tech Stack & Tools

* **HTML5:** Semantic structure and content architecture.
* **CSS3:** Custom styles, Flexbox, CSS Grid, Media Queries, and CSS Variables.
* **JavaScript (ES6):** DOM manipulation and dynamic cart state management.
* **Git & GitHub:** Version control and source code management.
* **Vercel:** Continuous integration and deployment platform.

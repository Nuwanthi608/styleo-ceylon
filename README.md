# 🛍️ STYLEO CEYLON | Luxury Fashion & Lifestyle E-Commerce

**STYLEO CEYLON** is a modern luxury fashion & lifestyle e-commerce website designed specifically for the Sri Lankan market. Built as part of **DecodeLabs Industrial Training (Project 1)**, this application demonstrates pure frontend capabilities, responsive architecture, and interactive user interfaces using core web technologies without reliance on heavy external frameworks.

---

## ✨ Features & Highlights

- 📱 **Mobile-First Responsive Design:** Seamless layout adaptation across mobile, tablet, and desktop screens using CSS Grid and Flexbox.
- 🎨 **2025 Modern Editorial Aesthetic:** Designed using a refined color palette (Ethereal Blue, Moonlit Grey, and Mocha Mousse) and custom typography pairs.
- 🔍 **Interactive UI Elements:** Dynamic shopping bag counter, mobile navigation menu toggle, and clean call-to-action buttons.
- 🛍️ **Curated Collections Display:** Grid layout presenting Sri Lankan luxury products (Silk Osari, Linen Wear, and Evening Wear).
- ♿ **Semantic & Accessible:** Built with HTML5 semantic landmarks (`<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`) ensuring web accessibility and SEO optimization.

---

## 🛠️ Tech Stack & Tools

- **HTML5:** Semantic structure and content architecture.
- **CSS3:** Custom styles, Flexbox, CSS Grid, Media Queries, and CSS Variables.
- **JavaScript (ES6):** DOM manipulation and dynamic interactivity.
- **Git & GitHub:** Version control and source code management.
- **Vercel:** Deployment and hosting platform.
